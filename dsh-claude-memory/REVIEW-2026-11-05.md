## 尚未实现边界的必要性

| 边界                           | 判断                           | 理由与替代方式                                                                                                                             |
| ------------------------------ | ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| CLI --settings / flagSettings  | 当前无需自动发现               | 这是另一个 Claude 进程的状态，DSH 无法可靠推断。已知目录可通过 configDir、memoryDir、projectDirName 显式指定；不应通过扫描进程或猜测补齐。 |
| MDM、远程 policy API           | 当前可延期                     | 当前个人 Mac 没有必须接入的证据；企业部署确有策略来源时，再做明确来源和认证的只读适配。文件式 policy 仍需正确遵循优先级，已修复。          |
| CLAUDE_CODE_PROJECT_DIR_NAME   | 保留兼容，不扩大承诺           | 已支持显式覆盖；核查的本地 Claude 源码未使用此变量，不能把它描述为现行官方能力。                                                           |
| Desktop 隔离配置               | 当前不必自动扫描               | 本机使用默认配置；其他版本用 configDir/CLAUDE_CONFIG_DIR。自动遍历 Application Support 会扩大读取范围和误识别风险。                        |
| Windows/Linux 未真实测试       | 跨平台发布前必须补验证         | 当前 Mac 使用不阻塞；仅使用 Node 平台 API 不等于完成跨平台验收。当前不宣称已通过这些系统的真实验证。                                       |
| 符号链接子目录跳过             | 保留                           | 减少循环和别名问题；越界链接必须拒绝。确有漏读案例后再加有界、去重的目录遍历。                                                             |
| 精确 token 计数                | 当前无需实现                   | tokenizer 与模型有关；字符预算是明确的近似。本次补上累计上下文上限、索引/清单上限以及准确的不完整报告。                                    |
| 单文件大小上限                 | 保留                           | 512KB 默认值可调，超过明确拒绝；不应无条件把超大文件全部放进上下文。单文件超过批次预算需调大预算，不能伪报完整。                           |
| 嵌套 MEMORY.md 当作普通主题    | 保留并说明                     | 本任务要求读取全部有效项目记忆，包含嵌套 .md 是合理选择；不需要为了模仿写入器扫描策略而删内容。                                            |
| 子 Agent 默认不注入索引        | 保留                           | 避免扇出时无谓复制记忆；内部委派不等于用户要求全量加载。明确需要时调用工具即可。                                                           |
| 父目录包含多个仓库时不猜子仓库 | 必须保留                       | 直接关系到仓库隔离；在目标仓库启动会话或明确指定目录。                                                                                     |
| nonce 提示不能形成硬安全边界   | 如实保留限制                   | 文本分隔不能保证模型不受内容影响。插件没有写入接口；整个 DSH 的工具授权与沙箱属于独立边界，不在 Reader 内重新实现。                        |
| Bun/Node 长路径 hash 不一致    | 安全处理必须有，自动兼容可延期 | 不能用“唯一前缀”替代身份验证；本次采取拒绝不确定匹配并提供显式覆盖。以后可增加可信的项目元数据证明。                                       |

真正必须补的是不持久化源正文、准确报告完整性、目录身份和跨会话隔离，不能把这些缺陷归为可接受的“尚未支持边界”。
